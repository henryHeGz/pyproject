# 留言公开爬虫更新说明

## 更新概览

留言公开爬虫已经进行了重大更新，现在采用全新的工作流程，更加灵活和透明。

---

## 核心变化

### 1. **工作流程变化**

**旧版流程：**
```
爬取 → 边抓取边去重 → 只保存新记录到数据库
```

**新版流程：**
```
爬取 → 抓取所有数据到内存（不去重）
     ↓
     → 保存到CSV文件（本次抓取的所有数据）
     ↓
     → 根据参数决定如何保存到数据库：
        - overwrite_db=False: 只插入新记录，跳过已存在的
        - overwrite_db=True: 更新已存在的记录，插入新记录
```

### 2. **新增功能**

#### ✅ 自动生成CSV文件
- 每次爬取完成后，自动生成包含本次抓取所有数据的CSV文件
- 文件命名格式：`comments_{task_id}_{timestamp}_{random}.csv`
- 文件保存在 `csv_exports/` 目录

#### ✅ 覆盖模式选项
- 新增 `overwrite_db` 参数（前端显示为"覆盖数据库已存在的记录"复选框）
- **不勾选**（默认）: 跳过已存在的记录，只插入新记录
- **勾选**: 更新已存在的记录，插入新记录

#### ✅ 任务记录追踪
- 每个任务保存本次抓取的所有记录ID列表
- 预览和导出功能只显示本次任务抓取的数据
- 不再显示数据库中的全部数据

## 使用指南

### 前端界面操作

#### 留言公开爬虫表单

```
📚 留言公开爬虫
├── 起始页码: 1
├── 最多抓取页数: (留空=全部)
├── ☑ 无头模式
├── ☐ 自动下载详情内容
└── ☐ 覆盖数据库已存在的记录  ← 新增
```

#### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 起始页码 | 从第几页开始抓取 | 1 |
| 最多抓取页数 | 限制抓取页数，留空表示抓取到最后一页 | 无限制 |
| 无头模式 | 后台运行浏览器，不显示窗口 | ✓ |
| 自动下载详情内容 | 抓取完列表后立即下载每条留言的详细问答内容 | ✗ |
| **覆盖数据库记录** | **如果记录已存在，是否更新覆盖** | **✗** |

```yaml

  起始页码: 1
```

```yaml
  - 预览/导出: 显示本次抓取的所有记录（无论新旧）
```

```yaml
  - 抓取第10-12页

  - 生成CSV文件包含完整问答内容
  - 数据库: 只插入新记录（带详情内容）
```

## 数据库行为详解

### 不覆盖模式 (overwrite_db=False)

```python
for record in all_scraped_records:
    if record.id in existing_ids:
        # 跳过，不做任何操作
        print(f"跳过已存在记录: {record.question}")
    else:
        # 插入新记录
        INSERT INTO comment_records ...
```

**适用场景**：
- ✅ 首次抓取数据
- ✅ 增量更新新出现的留言
- ✅ 避免覆盖已手动修改的数据

### 覆盖模式 (overwrite_db=True)

```python
for record in all_scraped_records:
    if record.id in existing_ids:
        # 更新已存在的记录
        UPDATE comment_records
        SET question = ..., date = ..., updated_at = NOW()
        WHERE id = ...
    else:
        # 插入新记录
        INSERT INTO comment_records ...
```

**适用场景**：
- ✅ 重新抓取以更新数据
- ✅ 修复之前抓取错误的数据
- ✅ 同步网站上已修改的内容

## 常见问题 FAQ

### Q1: 为什么每次都生成新的CSV文件？
**A:** 为了保留每次抓取的完整记录，便于追溯和对比。每个任务都是独立的快照。

### Q2: 如果我只想要新数据，CSV里还是包含重复的怎么办？
**A:** CSV文件包含本次抓取的所有数据（不去重）。如果只想要新数据，请使用任务结果中的 `new_records` 数量，或导出后手动过滤。

### Q3: "覆盖数据库记录"具体会更新哪些字段？
**A:** 会更新以下字段：
- question (留言问题)
- date (日期)
- link (链接)
- downloaded (是否下载)
- question_content (问的内容)
- answer_content (答的内容)
- updated_at (更新时间)

### Q4: 预览数据为什么只显示10条？
**A:** 预览默认限制为10条，完整数据请使用"导出CSV"功能。

### Q5: 我能同时运行多个爬取任务吗？
**A:** 可以，每个任务独立运行，生成独立的CSV文件和记录ID列表。
