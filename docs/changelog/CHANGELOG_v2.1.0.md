# 变更日志 v2.1.0 - Web界面多页签重构

## 发布日期
2025-10-17

## 概述
将原有的单页面Web界面重构为现代化的多页签架构，提供更清晰的功能组织和更好的用户体验。

## 新增功能 ✨

### 1. 多页签架构
- **主页** (`/`): 系统概览仪表板
  - 数据库统计卡片
  - 任务状态概览
  - 快捷操作入口
  - 最近活动列表

- **法律法规页签** (`/flfg`): 法律法规专属页面
  - 爬取列表功能
  - 下载详情功能
  - 数据库预览
  - 相关任务列表

- **留言公开页签** (`/comments`): 留言公开专属页面
  - 爬取留言功能
  - 下载详情功能
  - 数据库预览
  - 相关任务列表

- **任务管理页签** (`/tasks`): 任务集中管理
  - 运行中任务监控
  - 已完成任务列表
  - CSV文件管理
  - 任务操作（预览、导出、日志）

### 2. 视觉改进
- 统一的UI设计语言
- 现代化的卡片布局
- 清晰的导航栏
- 响应式设计（支持移动设备）

### 3. 技术改进
- 静态资源管理（`/static`路由）
- 模板化设计（易于维护和扩展）
- 独立的CSS样式文件
- 保持API向后兼容

## 路由变更 🛣️

### 新增路由
- `GET /` - 主页
- `GET /flfg` - 法律法规页面
- `GET /comments` - 留言公开页面
- `GET /tasks` - 任务管理页面

### 静态资源
- `GET /static/*` - 静态文件服务

### API路由
- 所有现有API路由保持不变
- 向后兼容，无破坏性变更

## 使用示例 💡

### 启动应用
```bash
python web_app.py
```

### 访问页面
- 主页: http://localhost:8000/
- 法律法规: http://localhost:8000/flfg
- 留言公开: http://localhost:8000/comments
- 任务管理: http://localhost:8000/tasks

### 功能演示
1. **主页**: 查看系统整体状态
2. **法律法规**: 提交爬取任务，查看数据预览
3. **留言公开**: 提交留言爬取任务，管理留言数据
4. **任务管理**: 监控所有任务，导出CSV，查看日志
