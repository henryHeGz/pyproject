# 法律法规详情下载功能说明

## 功能概述

法律法规爬虫现在支持两个独立的功能：

1. **爬取列表** - 爬取法律法规列表页，获取标题、发文字号、成文日期、链接等基本信息
2. **下载详情** - 根据CSV中的链接，下载每个法规的完整文档和附件（新增功能）

## 使用流程

### 方法一：Web界面操作

1. 启动Web服务
```bash
./start_web.sh
# 或
python3 web_app.py
```

2. 访问 http://localhost:8000

3. 操作步骤：
   - **步骤1**: 使用"📚 法律法规爬虫"卡片，爬取列表数据
   - **步骤2**: 使用"📥 下载法律法规详情"卡片，下载文档详情

### 方法二：命令行操作

```bash
# 1. 先爬取列表
cd flfg_scraper
python chinatax_scraper.py --csv chinatax_flfg.csv --start-page 1 --page-count 5

# 2. 再下载详情
python chinatax_scheduler.py --csv chinatax_flfg.csv --not-downloaded --limit 10
```

## Web界面参数说明

### 下载法律法规详情

**CSV文件路径**
- 包含法规列表的CSV文件（必须先通过法律法规爬虫生成）
- 默认：`chinatax_flfg.csv`

**输出目录**
- 下载的文档保存位置
- 默认：`./flfg_downloads`
- 每个法规会创建独立的文件夹，例如：`国家税务总局公告2021年第26号_5194992`

**最多下载数量**
- 限制一次下载的法规数量
- 留空表示下载所有符合条件的
- 建议：首次测试设置为 1-5 条

**无头模式**
- 勾选：浏览器在后台运行，不显示窗口
- 不勾选：显示浏览器窗口，可以看到下载过程

**只下载未下载的**
- 勾选：只下载CSV中"是否下载"列为"N"的记录
- 不勾选：下载所有记录（不推荐，会重复下载）

## 下载内容说明

每个法规文档会被保存在独立的文件夹中，包含：

1. **主文档** - 法规正文（通常为.doc/.docx/.pdf格式）
2. **附件** - 如果法规有附件，会保存在`附件`子文件夹中

文件夹命名示例：
```
flfg_downloads/
  ├── 国家税务总局公告2021年第26号_5194992/
  │   ├── 国家税务总局公告2021年第26号.doc
  │   └── 附件/
  │       ├── 附件1.pdf
  │       └── 附件2.xlsx
  ├── 国家税务总局令第XX号_1234567/
  │   └── ...
```

## 下载状态管理

- 下载成功后，CSV中的"是否下载"列会自动更新为"Y"
- 下次运行时，勾选"只下载未下载的"会自动跳过已下载的记录
- 支持断点续传：如果下载中断，重新运行会从未下载的继续

## 常见场景

### 场景1：首次完整下载

1. 先爬取列表（如前10页）
2. 测试下载1条记录，确认正常
3. 批量下载所有记录（或分批下载，如每次50条）

### 场景2：增量更新

1. 运行列表爬虫，获取新增的法规
2. 只下载新增记录的详情（自动跳过已下载的）

### 场景3：限量下载

1. 设置"最多下载数量"为10
2. 每天定时下载10条未下载的记录

## 注意事项

1. **下载时间**：每个法规下载需要5-15秒，批量下载需要较长时间
2. **网络稳定性**：建议在网络稳定的环境下运行
3. **存储空间**：确保有足够的磁盘空间，每个法规通常1-10MB
4. **并发限制**：当前版本串行下载，不支持并发（避免对服务器压力过大）
5. **错误处理**：个别法规下载失败不会中断整个任务，会继续下载下一条

## API接口

如果需要通过API调用：

```bash
curl -X POST "http://localhost:8000/api/flfg/download" \
  -H "Content-Type: application/json" \
  -d '{
    "csv_path": "chinatax_flfg.csv",
    "output_dir": "./flfg_downloads",
    "max_downloads": 10,
    "headless": true,
    "only_not_downloaded": true
  }'
```

返回任务ID，然后查询任务状态：
```bash
curl "http://localhost:8000/api/task/{task_id}"
```

## 技术实现

- 使用 Playwright 自动化浏览器访问每个法规页面
- 自动查找并点击下载按钮
- 提取页面中的所有附件链接
- 智能识别文件类型（.pdf, .doc, .docx, .xls, .xlsx等）
- 保持会话状态，处理需要cookies的下载

## 故障排除

**问题1：下载失败 - "未找到可用的下载按钮"**
- 原因：部分法规页面可能没有下载按钮
- 解决：这是正常现象，程序会继续下载下一条

**问题2：下载的文件无法打开**
- 原因：文件可能损坏或格式不支持
- 解决：检查源网站，有些可能需要特殊查看器

**问题3：CSV更新失败**
- 原因：文件被其他程序占用
- 解决：关闭Excel等正在打开CSV的程序

**问题4：任务一直运行不结束**
- 原因：某个页面加载超时
- 解决：停止Web服务重启，下次会跳过已下载的继续
